# 04 · 视觉设计规范

**方向名：** 纸艺绘本岛（Paper-cut Storybook Island）
**关键词：** 温暖、手作、圆润、清晰、会呼吸的纸片
**设计目标：** 3 米外一眼看懂，近看有手作细节；像一本会动的儿童绘本，而不是一套彩色 PPT。

> 本文是视觉语言与组件规范。`design/mockups/` 下有 1920×1080 的 SVG 评审稿；SVG 稿中使用 macOS 系统字体作近似，正式开发改用文末列出的 OFL 字体。

---

## 1. 视觉方向

### 1.1 是什么

- **纸艺拼贴：** 山、树、云、角色像一层层彩色纸片叠出来，有清晰的深色轮廓与轻微错位的投影。
- **软陶质感：** 角色脸部和果实有柔和的体积感，用两三个色阶表现高光与阴影，而不是写实渲染。
- **儿童绘本排版：** 大标题、手写感、留白；画面元素有呼吸感，不把屏幕塞满。
- **低细节、高辨识：** 3 米外先看到轮廓和颜色，再看到纹理；每个场景只有一个视觉中心。

### 1.2 不要什么

- 不要高饱和霓虹色、塑料感 3D、镜头光晕、满屏渐变。
- 不要廉价“AI 卡通”：相同的大眼睛、无意义的渐变球、漂浮粒子、过度光滑。
- 不要细线、小字、低对比、灰蒙蒙的“高级感”。
- 不要用颜色单独表示对错或焦点。
- 不要恐怖、尖锐、攻击性表情；没有反派和怪物。
- 不要出现任何已有 IP 的角色、配色组合或标志性道具。

### 1.3 质感配方

| 元素 | 做法 |
|---|---|
| 纸张底 | 奶油底色 + 极低透明度纸纹（SVG pattern，不用噪点滤镜） |
| 轮廓 | 主要形状 4–6px 墨蓝描边；内部细节 2–3px |
| 阴影 | 同形状向下偏移 6–10px，墨蓝 10–15% 透明度，不用模糊滤镜 |
| 高光 | 形状内部偏左上的一层更浅色块，边缘圆润 |
| 叠层 | 背景 / 中景 / 前景 / 角色四层，前景叶片可轻微遮挡 UI 外缘 |
| 纹理 | 少量短线、点点、纸片缺口；不铺满、不影响识数 |

### 2.2 语义色

- **正确：** `leaf` + `sun` 星星 + 上扬的弧线；不只靠绿色。
- **需要再试：** `coral` 的柔和色 + 轻晃 + 萤萤“想一想”；不使用红色大叉。
- **焦点：** `sun` 外圈 + `ink` 内描边 + 上浮 + 三角指针；在浅底和深底都能看见。
- **锁定：** `ink` 40% + 小锁图标 + 降低明度；不把锁定关卡完全隐藏。
- **禁用：** 基本不使用禁用态；游戏里没有需要孩子理解的“不可用按钮”。

### 2.3 对比度要求

- 儿童可见文字与底色：≥ 4.5:1（大字号至少 3:1）。
- 焦点环与任意背景：亮度差足够，并且同时有粗细/位移/箭头变化。
- 不用纯白背景 + 纯黑文字（刺眼）；用奶油 + 墨蓝。
- 灰度检查：去掉颜色后，焦点、数字、正确/错误仍能区分。

## 3. 字体与数字

### 3.1 正式字体（均为 OFL 授权，可随 APK 打包）

| 角色 | 字体 | 用法 | 备注 |
|---|---|---|---|
| 中文标题/关卡名 | **ZCOOL KuaiLe**（站酷快乐体） | 仅标题、按钮、角色名 | 不用于长段落 |
| 中文正文/家长区 | **Noto Sans SC** | 说明、家长区、字幕 | 字重 400/600 |
| 数字 | **Fredoka** SemiBold/Bold | 数字卡、计数编号、HUD | 数字字形清晰，不用装饰变体 |

- 字体随 APK 打包 WOFF2 子集；只包含实际用到的字形。
- 保留 OFL 许可证文本，并在家长区“关于”中列出。
- 设计稿中使用 `Hannotate SC`、`Arial Rounded MT Bold` 作近似；正式版以 OFL 字体为准。
- 绝不打包 macOS 系统字体或任何未授权中文字体。

### 3.2 字号（1920×1080 设计稿）

| 层级 | 字号 | 行高 | 用途 |
|---|---:|---:|---|
| 品牌标题 | 110–132px | 1.05 | 首页主标题 |
| 屏幕标题 | 72–88px | 1.1 | 关卡完成、家长区标题 |
| 题目主字 | 56–64px | 1.25 | 萤萤问题、任务卡 |
| 选项数字 | 148–176px | 1 | 数字卡 |
| 儿童可见短句 | 44–52px | 1.3 | 按钮、提示 |
| 控制提示 | 32–36px | 1.2 | 键位图例、重听提示 |
| 家长区正文 | 28–32px | 1.6 | 说明、隐私、共玩 |
| 最小可读 | 24px | — | 仅家长入口提示等非关键文字 |

- 儿童核心内容不小于 44px；家长入口的 24px 文字不是孩子需要阅读的内容。
- 中文不拉开字距，不加粗到糊；英文标签只在品牌装饰中使用。
- 数字和汉字不要混用艺术字形到影响认读；`4`、`7`、`9` 必须用标准开口/闭口形态。

## 4. 版式与安全区

- 基准画布：**1920×1080**，横屏，等比缩放。
- 安全边距：水平 ≥ **96px**，垂直 ≥ **64px**；重要内容再内缩到 **120px / 96px**，兼容电视 overscan。
- 空白：画面边缘至少留出 1/8 的呼吸区；标题/问题/HUD 形成一个稳定的视觉三角。
- 视觉中心：每题只能有一个“主视觉”（被数的花朵、比较的两组、规律小径）。
- 底部控制提示固定位置，但不抢焦点；没有操作 8 秒后降低不透明度到 55%。

### 4.1 答题页纵向分区

| 区域 | Y 范围 | 内容 |
|---|---:|---|
| HUD | 44–112 | 关卡徽章、3 格题目进度、数字星总数 |
| 问题气泡 | 126–292 | 萤萤头像、问题、重听图标 |
| 主场景 | 300–606 | 可数对象 / 比较组 / 规律 / 队列 |
| 选项区 | 636–954 | 3 张大卡，等宽 432px，间距 56px |
| 控制提示 | 990–1024 | ◀ ▶ 选择 · OK 确定 · ↑ 再听 |

### 4.2 首页与地图

- 首页：标题位于左上黄金区；主按钮靠左下，狐狸和灯塔形成右侧对角平衡。
- 地图：起点在左下，路径向右上蜿蜒；焦点节点始终处于画面中上部的视觉焦点区。
- 地图移动不做整页滚动，使用镜头平移；锁定节点仍可见，给孩子“前面还有”的期待。

## 5. 核心组件规范

### 5.1 焦点按钮

- 尺寸：主按钮 560×136px；次按钮 430×112px。
- 圆角：主按钮 48px；卡片 40px；地图节点圆形。
- 正常态：奶油/向日葵纸片 + 4px 墨蓝描边 + 向下 8px 的纸质投影。
- 焦点态：**上浮 12px + 放大 1.04 + 12px 向日葵外圈 + 4px 墨蓝内圈 + 底部小三角 + 短促“嗒”音效**。
- 按下：缩小到 0.98，投影变短，约 120ms；确认后立即锁定，防止双击。
- 文字：主按钮 52px 墨蓝，不用白字；次按钮深青底白字时确保 ≥ 5:1。
- 不使用纯色填充 + 白色细字这种远距离不可读组合。

### 5.2 数字选项卡

- 尺寸：432×318px，圆角 40px。
- 结构：顶部小彩纸标签（可选图标）+ 中央大数字 + 底部小图形提示。
- 正常：奶油纸面，4px 墨蓝边，颜色区分度低。
- 焦点：向日葵外环 + 上浮；数字略微放大；卡片下方的三角指向键位。
- 正确：数字变深青、星形徽章出现、花瓣/纸片从卡片边缘散开；**不使用绿色大勾盖住数字**。
- 错误：不出现叉；卡片轻晃 6°，萤萤说话；数字仍清晰可见。
- 三张卡必须等大、等距；焦点卡放大后不能遮挡相邻卡的数字。

### 5.3 问题气泡

- 1120×166px，奶油纸面，墨蓝 4px 边，圆角 54px；右下有小尾巴指向场景。
- 左侧 112px 萤萤头像；右侧 96px 重听按钮。
- 问题文字最多 18 个汉字，56px；数字可单独放大加粗。
- 重听按钮不是独立焦点；`↑` 键触发，按钮高亮 150ms 并播放“叮”的音效。
- 字幕开关打开时，在气泡下方显示 36px 字幕条，不遮挡场景。

### 5.4 HUD

- 左上：关卡徽章（木质/纸片），例：`青芽森林 · 第 1 关`，40px。
- 中上：3 格题目进度（1/2/3），当前题；不使用第二套货币。
- 右上：数字星图标 + `4 / 10`，36px；不放设置齿轮（孩子不需要）。
- 不显示时间、分数、生命值或“失败”。

### 5.5 地图节点

- 直径 96px 的圆形纸片；外圈 6px 墨蓝；内部放数字/小图标。
- 已完成：向日葵底 + 1 颗数字星 + 轻微高光；数字星总数与地图 HUD 一致。
- 当前：奶油底 + 金色外环 + 萤萤停在旁边；下方纸标签显示关卡名。
- 锁定：灰绿底 + 小锁 + 50% 明度；仍然可见、可聚焦，按 OK 会语音提示“先完成前面的关卡”。
- 当前节点必须有唯一最强的视觉重量；不能所有节点一样亮。

### 5.6 控制提示

- 固定底部居左或居中：小键帽图形 + 32px 文案。
- 键帽：48×48px 奶油圆角方块，墨蓝 3px 边，内部箭头。
- 答题页始终显示：`◀ ▶ 选择` `OK 确定` `↑ 再听`。
- 首页/地图显示：`◀ ▶ 选择` `OK 确定` `返回 回退`。
- 提示永远同一位置、同一顺序，建立肌肉记忆。

## 6. 角色设计

### 6.1 点点（小狐狸，主角）

- **体型：** 约 2.5 头身；头宽 220px（1080p 全身约 480px 高）；大头、短腿、圆肚。
- **颜色：** 主体珊瑚橙 `#E88755`，亮部 `#F4A46F`，深部 `#C9633F`；口鼻/胸腹奶油 `#FFF1D8`；耳内玫瑰 `#F6C7B9`；围巾湖水绿 `#2A9D8F`。
- **特征：** 大耳朵、蓬松尾巴、星星布包；不穿鞋，脚掌简单圆润；三根短胡须或省略。
- **表情：** 中性（好奇）、开心（弯眼）、思考（一只眼眯、耳朵一高一低）；不出现生气、嘲笑、哭泣。
- **动作：** 呼吸（胸腔 ±2%）、眨眼（每 4–7 秒）、尾巴左右 3°；开心时轻跳一次。
- **性格：** 和孩子一起探索，不居高临下“教”；答错时点点也会歪头思考。

### 6.2 萤萤（旁白，小萤火虫）

- 直径 72–96px 的发光小球，暖黄色；两片半透明翅膀；极简笑脸。
- 声音的视觉化身：说话时轻轻上下浮动，翅膀快速振动；重听时绕圈飞一下。
- 发光用 3–4 圈半透明同心圆，**不用高斯模糊**；避免满屏光晕。

### 6.3 守护者

| 角色 | 世界 | 外形 | 性格 |
|---|---|---|---|
| 果果 | 青芽森林 | 小松鼠，棕色大尾巴，背小挎包 | 热心、爱种花 |
| 糖糖 | 糖果镇 | 小熊，焦糖色，围裙上有糖果图案 | 慢吞吞、爱分享 |
| 星宝 | 星光城堡 | 紫灰色小猫头鹰，戴星星眼镜 | 聪明、温柔、喜欢规律 |

守护者只在开场、关卡完成和地图出现，不抢萤萤的旁白角色。

## 7. 三个世界 + 终章

### 7.1 青芽森林（1–3 关）

- 时间：清晨；天空 `#CDEFF3` → 奶油色地平线。
- 元素：层叠草坡、圆冠树、花朵、蘑菇、木牌、溪流石桥。
- 色彩：湖水绿 + 叶子绿 + 珊瑚花 + 向日葵黄；木头用暖棕。
- 气质：安全、柔软、有生命力；不出现密林阴影。

### 7.2 糖果镇（4–6 关）

- 时间：午后；天空 `#FBE3DA`，糖果色但降低饱和度。
- 元素：拐杖糖、软糖山、玻璃糖果罐、小火车、巧克力铁轨（不写实）。
- 色彩：珊瑚 + 奶油 + 葡萄紫 + 薄荷绿平衡，避免整屏粉红。
- 气质：甜而不腻；糖果是图形，不是诱发多吃的广告。

### 7.3 星光城堡（7–9 关）

- 时间：黄昏到初夜；夜空 `#4E5D8C` → `#8E7CC3`，仍有奶油色前景保证亮度。
- 元素：纸片塔楼、星星、月牙、云朵、望远镜、星图。
- 色彩：深青 + 葡萄紫 + 金色星光 + 奶油前景。
- 气质：神秘但不黑、不吓人；城堡是“安静的图书馆”，不是鬼屋。

### 7.4 星光灯塔（终章）

- 时间：庆典夜；晚霞 + 星光。
- 元素：条纹灯塔、光束、彩旗、纸片烟花、全体角色剪影。
- 色彩：珊瑚/蜜桃 + 深青 + 金色；庆祝但不闪爆屏幕。
- 完成画面保持克制：光束缓慢旋转，星星缓落，不持续放烟花。

## 8. 动效与声音

### 8.1 动效原则

- 所有动效都有“起点—停顿—终点”，不做无意义的循环闪烁。
- 只动 `transform` 和 `opacity`；避免大范围 `box-shadow` 动画。
- 时长：焦点 180–250ms；按钮按下 120ms；答对 300–450ms；关卡完成 1.5–2.5s。
- 缓动：`cubic-bezier(0.22, 1, 0.36, 1)` 出场；`ease-out` 收尾。
- 减少动态：关闭粒子、浮动、视差和尾巴摆动，只保留必要的焦点与状态过渡。
- 无 >3Hz 闪烁；没有突然全屏白/黑；庆祝粒子在 1.5 秒内结束。

### 8.2 声音

- 音乐：木琴、钢片琴、轻拨弦、柔和低音；速度 80–100 BPM；每世界一条 45–60 秒循环。
- 旁白：温柔、清晰、慢速；句间留 300–500ms；不用夸张的“儿童节目腔”。
- 正确：上行三音 + 星星轻响；错误：软木“咚”+ 萤萤气声，不用蜂鸣。
- 焦点：极短的木质“嗒”；音量低于旁白很多。
- 混音：旁白优先；BGM 在旁白时降到 20–30%；所有音效无突发大音量。
- 静音可玩：所有关键题都有图形表达；家长可开字幕。

## 9. SVG 制作规范

### 9.1 文件

- 每个场景/角色/图标一个 SVG 源文件；使用 `viewBox`，不写死 `width/height` 为唯一尺寸。
- 文件名：`scene-forest-garden.svg`、`char-fox-happy.svg`、`ui-answer-card.svg`、`numeral-3.svg`。
- **禁止** `<image>`、`<script>`、外链 `href`、远程字体、内嵌 base64 位图。
- 需要动画的部件用稳定 class/id：`.fox-eye-left`、`.fox-tail`、`.firefly-wing`。
- 保持语义分组：`bg-`、`mg-`、`fg-`、`char-`、`ui-`。
- 正式资源内联到页面，不用 `<img>`，以便焦点/动画控制和避免额外请求。

### 9.2 复杂度预算

- 单个场景源文件 ≤ 150KB；单屏 DOM 节点 ≤ 2500。
- 主要轮廓 4–6px；细节 2–3px；3 米外看不到的细节直接删掉。
- 慎用：`filter`、`mask`、大面积透明渐变、超过 3 层的纹理叠加。
- 发光用同心半透明圆，不用 `feGaussianBlur`。
- 阴影用偏移副本，不用模糊滤镜。
- 所有计数对象必须同形同色、互不遮挡；规律题才使用多形状。

## 10. 可访问性与“电视可见性”

- 灰度测试：去掉颜色后，数字、焦点、正确/错误仍可区分。
- 3 米测试：缩小到 1280×720 并退后观看，能否在 2 秒内找到焦点和问题。
- 焦点永不丢失；地图移动时焦点元素保持在安全区内。
- 家长区与字幕文字至少 28px；儿童核心内容至少 44px。
- 题目语音必须有图形备份：数字题展示数字，比较题展示两组实物，规律题展示图案。
- 颜色对比符合 WCAG AA；不使用红色/绿色作为唯一语义。
- 允许“减少动态效果”和字幕；所有声音内容都不作为唯一信息通道。

## 11. 设计验收清单

- [ ] 3 米外能看清题目的“主视觉”和当前焦点。
- [ ] 所有关键信息在 5% overscan 安全区内。
- [ ] 焦点有至少 3 种非颜色线索（粗环、上浮、箭头）。
- [ ] 数字卡上的数字不被装饰遮挡，`4/7/9` 形态标准。
- [ ] 俯视/灰度截图仍能区分焦点、正确和可选项。
- [ ] 答错时没有红叉、蜂鸣、哭泣或“失败”字眼。
- [ ] 角色表情友善；没有尖锐牙齿、怒视、攻击姿势。
- [ ] 每个场景只有一个视觉中心；背景不抢题目。
- [ ] 未出现任何第三方 IP、未授权字体/图像/音效。
- [ ] SVG 无外链、无位图、无脚本；总包体符合预算。
- [ ] 1920×1080 / 1280×720 截图都完整，不裁切、不变形。
