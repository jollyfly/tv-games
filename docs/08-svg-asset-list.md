# SVG 美术资源清单 · v2.2 美术精修

> 目标：把现在“能看出是什么”的扁平符号，升级为**有结构、有层次、有动画**的手绘纸艺 SVG。
> 原则：先角色/生物，再地图道具，再微游戏专属小物，最后特效和 UI。
> 状态：`[ ]` 待生成/重绘，`[~]` 初版待精修，`[x]` 已完成。

## 0. 美术标准

- 4–5 岁电视距离可读：大轮廓、粗深色描边、少细节但结构正确。
- 每个生物至少包含：**头/躯干/附肢/眼睛/纹理/高光**，不能用一个圆形加两根触角代替。
- 每个道具至少包含：**主体 + 2 层以上的明暗/纹理 + 投影**。
- 配色沿用纸艺奶油色，但每张地图有自己的主色和辅助色。
- 动画只做“呼吸、摆动、发光、飘落”这类轻柔循环；尊重“减少动态效果”。
- 全部原创 SVG，不复制现有动画角色。
