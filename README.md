# 数字岛大冒险 · v2.4.0

**小米电视 / Android TV 上的 4–5 岁数字与逻辑闯关游戏**
**10 张主题地图 × 每图 10 关 = 100 关 / 300 道微任务**

APK：**[number-island-tv-2.4.0-debug.apk](release/number-island-tv-2.4.0-debug.apk)** · 19 MB · [安装说明](INSTALL.md)

和点点、萤萤、小龟、小恐龙隆隆、星仔、哆哆一起，穿过十座数字岛，收集 100 颗数字星。

---

## 十张地图

1. **青芽森林** — 数感启蒙
2. **糖果镇** — 数量与分配
3. **星光城堡** — 规律与序数
4. **云上天空** — 飞行观察、云朵目标
5. **海底奇遇** — 数字捕鱼、珍珠、珊瑚迷宫
6. **恐龙化石谷** — 化石、恐龙蛋配对、找不同
7. **星际数字站** — 星图坐标、火箭轨道、舱门密码
8. **音乐泡泡镇** — 音符规律、节拍排队、泡泡数量
9. **甜甜圈工厂** — 装盒、平分、订单配对
10. **魔法花园** — 变形、找不同、数量关系

每张地图进入后是独立的 10 关路线；每 10 关完成解锁下一张地图。首页「关卡地图」进入十座岛选择页。

---

## 玩法与规则

- **100 关 / 300 题**：点数、数字→数量、顺序、比较、规律、序数、3×3/5×5/6×6 数字迷宫，以及新增的 **找不同**、**星图坐标**、**甜甜圈平分**。
- **只用遥控器**：左右/上下选择，OK 确认，上键再听，返回暂停。
- **全局无提示**：答错不再自动给提示、不砍选项、不揭答案；同一道题会 **重新生成一组选项并洗牌**，可无限重试。
- **不靠背位置**：每道题的选项顺序随机；比较关的左右数量随机交换。
- **数字迷宫**：不显示下一个数字、不显示路线点、不高亮方向；走错直接回到起点。
- **逐题独立语音**：每关引导、每道题都用 CosyVoice3 单独生成，共约 401 条；没有通用题型配音。
- **原创平台感 BGM**：132 BPM 弹跳低音、反拍和弦、短促主旋律、鼓组和沙锤；每张地图有调性/配器变化。
- **地图切换特效**：世界卡进入单图时用主题色光圈擦除，返回时反向收回；支持「减少动态效果」。
- **强化奖励**：答对星星爆开；关卡完成有星星雨、金色光环、贴纸弹跳、3 段小号角；第 10 关额外显示地图完成丝带。
- **完全离线**：APK 不申请任何 Android 权限（包括 INTERNET）。

## 安装

1. 下载 **[APK](release/number-island-tv-2.4.0-debug.apk)**（debug 签名，家庭侧载用）。
2. 电视允许「安装未知来源应用」。
3. U 盘拷贝 APK，或用 ADB 覆盖安装。
4. 到电视「我的应用」启动《数字岛大冒险》。

详细 U 盘/ADB 步骤、遥控器说明与常见问题见 **[INSTALL.md](INSTALL.md)**。

## 开发与验证

```bash
cd number-island-tv
./scripts/build-apk.sh
```

- Web: Vite + TypeScript + 内联 SVG，无运行时框架
- 原生壳：Kotlin + WebView + WebViewAssetLoader
- 全 100 关 Playwright 自动通关（含随机选项、找不同、星图坐标、平分、5×5/6×6 迷宫）
- 逐题语音：CosyVoice3，本地离线生成
